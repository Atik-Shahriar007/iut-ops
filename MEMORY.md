# IUT Ops — Memory

The supplied archive contains five mixed-angle references rather than a complete top-down survey, so the game intentionally uses a compact stylized interpretation of the campus. The central water court and gateway are the orientation landmark; the sports lawn and residence block provide readable flanks. The current build avoids identifiable people and does not claim survey-level accuracy.

Babylon is imported from `@babylonjs/core`. The brick texture is served from Manus storage instead of being committed as a large binary asset. The `?demo` query flag enables a deterministic camera orbit for screenshot verification.
